# 12. Creative

Creative takes a client from research to produced ads: choose the messaging, write the scripts, get them approved, produce voices and music, and upload the ads for review.

[Creative Production](./creative-production.md) is the process the team follows. The other pages are the reference that still needs to be written: client notes, messaging types, the script template, how to brief Claude, file titling, mixing, ElevenLabs, and audio best practices. Until a reference page is filled in, follow the production steps and treat that page as an outline.

When an ad is approved, Rev Ops ingests the file in [Creative Management](../05-ad-operations/creative.md).
