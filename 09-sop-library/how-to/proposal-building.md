# How To: Build and Review a Proposal

> **Department / Section**: 09-sop-library / how-to  
> **Supports**: [Proposals & Contracting](../../03-sales/proposals.md), [Sales Process](../../03-sales/sales-process.md)  
> **Last Reviewed**: 2026-10-08  
> **Source**: *Audiohook Proposal Building Process* + *Proposal Review Call Process*

---

## Trigger

Parent task enters **Proposal Building** when required Data Collection subtasks are complete (technical connection + questionnaire/information).

---

## Build checklist

- [ ] Start from the current standard Audiohook proposal template
- [ ] Add client logo; complete cover and introduction pages
- [ ] Brand overview reflects discovery + questionnaire (not generic copy)
- [ ] Client and partner contacts accurate
- [ ] Tracking, reporting, and billing pages match intended custom fields (direct CC vs affiliate billing vs affiliate reporting-only)
- [ ] GA4 / funnel (or Shopify path) connection status documented honestly
- [ ] Prior audio experience and current marketing mix captured
- [ ] Conversion architecture and purchase-journey findings explicit
- [ ] Seasonality, launch dependencies, and creative plan documented
- [ ] Campaign goals and performance targets numeric and agreed-ready
- [ ] CPA vs CAC framing clear; projected monthly spend stated
- [ ] Phase 1 geography and targeting generated and justified
- [ ] Executive Summary complete and consistent with the deck
- [ ] Incentives / promotional terms (if any) accurate
- [ ] Timeline and prelaunch checklist realistic
- [ ] Commercial terms match what contracting will issue

---

## Required parent-task links (before Leadership Review completes)

1. Proposal Deck  
2. Executive Summary  
3. Creative Brief  

Also complete proposal-building field validation and resolve configuration conflicts so Contract Signed automations route correctly.

---

## Leadership Review gate

- [ ] Leadership has reviewed the proposal
- [ ] SAE has verified all parent-task fields
- [ ] Approved → Client Proposal Review  
- [ ] Not approved → remain in / return to Proposal Building

Do not present to the client before Leadership approval.

---

## Client Proposal Review — validate explicitly

On the call, validate (do not assume):

* Purpose of the custom plan and Audiohook sales path
* Client Success plan and who they will work with post-signature
* Tracking, reporting, and billing path
* Funnel / GA4 (or equivalent) validation
* Conversion architecture and journey findings
* Goals, CPA/CAC, expected spend
* Phase 1 GEO and targeting
* Timeline / prelaunch checklist
* Commercial terms

Philosophy: the review confirms shared operating truth before contracting — not a slide read-through.

---

## Contracting handoff

When the client agrees to proceed:

1. Move into Contracting; issue IO (+ affiliate addendum when fields require it)
2. Attach signed docs to the parent task
3. On full signature → **Contract Signed** → follow [Sales-to-CS Handoff](../../03-sales/handoffs.md)
