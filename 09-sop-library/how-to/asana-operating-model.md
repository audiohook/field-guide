## How to use the manual

Portfolio tabs define structure and routing. Project tabs define execution. When a specialized project tab exists, it is authoritative for that workflow.

The manual also has a tab for each affiliate platform onboarding path, marketing workflow, and post-launch request type. Use the tab list inside the doc to open the one you need.
