# 09. SOP Library

The **Standard Operating Procedure (SOP) Library** stores task-level, click-by-click instructions, screenshots, and operational checklists that support our core EOS processes.

---

## The EOS Difference: Core Process vs. Checklist vs. SOP

* **Core Process (Sections 01–08)**: High-level overview of the 20% of steps that produce 80% of results. Defines the sequence, accountability seat, measurables, and escalation paths.
* **Checklists (Section 09 / checklists)**: The Followed-by-All execution layer for Revenue — stage gates that match Asana Kanban. Prefer these for daily work.
* **How-To SOPs (Section 09 / how-to)**: Granular tool instructions or short pointers. Deep current-state Asana narrative stays in the operating-model Google Doc unless a checklist gap requires it here.

---

## Library Structure

* 📂 **[How-To Guides](./how-to/README.md)**: Detailed tactical how-to walkthroughs organized by department and tool.
* 📋 **[Checklists](./checklists/README.md)**: Reusable pre-flight, launch, QA, and audit checklists.
