# Checklist: Take-Live Readiness

> **Department / Section**: 09-sop-library / checklists  
> **Supports**: [Client Onboarding](../../04-customer-success/client-onboarding.md), [Campaign Launch](../../04-customer-success/campaign-launch.md)  
> **Owner**: Assigned CSM  
> **Last Reviewed**: 2026-09-18

Do not move the Asana parent task to **Take Live** or activate the campaign until every item below is complete or explicitly marked N/A.

---

## Account & workspace

- [ ] Contract executed; parent task is the same brand record used in Sales
- [ ] CSM owns the parent task
- [ ] Advertiser account created (Advertiser ID / UUID available)
- [ ] Client-specific Asana project exists in the Clients portfolio
- [ ] Google Drive client folder exists and is linked from Asana

## Relationship

- [ ] Sales introduced the CSM; CSM replied
- [ ] Onboarding call completed
- [ ] Campaign goals, audience, geo, and KPI targets confirmed on the call
- [ ] Follow-up actions documented in the client Asana project

## Billing

- [ ] Billing method matches Asana custom fields
- [ ] Direct CC: Stripe card on file
- [ ] Affiliate billing: program terms created and specialist-approved
- [ ] Affiliate reporting + direct billing: **$0 CPA / $0 reporting terms** confirmed
- [ ] Referral partner (if any) recorded in referral reporting
- [ ] Promotional terms documented for Accounting (or N/A)

## Tracking

- [ ] Parent task multi-homed into the correct tracking-onboarding project(s)
- [ ] Pixel, Shopify, S2S, Universal Tag, and/or affiliate tracking subtasks complete
- [ ] Test conversions visible before first bid

## Creative

- [ ] Creative Overview routing complete
- [ ] Launch messaging types selected
- [ ] Launch audio (and companion assets, if any) complete and approved

## Launch communications (after activation)

- [ ] Campaign-live email sent to the client
- [ ] Internal Slack announcement posted
- [ ] Everflow Pay recurring payment request set (or N/A)
- [ ] Parent task moved to **In Testing**
- [ ] Incrementality task moved from queue to **Week 0**
