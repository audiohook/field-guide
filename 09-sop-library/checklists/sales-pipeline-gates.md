# Checklist: Sales Pipeline Stage Gates

> **Department / Section**: 09-sop-library / checklists  
> **Supports**: [Sales Process](../../03-sales/sales-process.md), [CRM Hygiene](../../03-sales/crm.md), [Proposals](../../03-sales/proposals.md)  
> **Owner**: Assigned SAE  
> **Last Reviewed**: 2026-10-08

Work the Asana Sales Pipeline left to right. Complete the gate for your current stage before advancing. One parent task per brand.

---

## Lead entry → SQL

- [ ] SAE assigned; lead source / referring partner preserved
- [ ] Clarify deal created or updated
- [ ] Sales Qualified = Yes (else Disqualified + Clarify Closed-Lost)
- [ ] Duplicate questionnaire task merged if needed

## Discovery / Meeting Booked

- [ ] Discovery Call Date set (and kept accurate if rescheduled)
- [ ] Homework done (brand, funnel, prior audio if any)
- [ ] Call completed; next step is Data Collection

## Data Collection

- [ ] Technical connection started / complete (GA4 today; Shopify path when applicable)
- [ ] Questionnaire complete (or confirmed already on parent task)
- [ ] Enough economics, measurement, GEO, and success definition to build a proposal
- [ ] Clarify next step updated
- [ ] All required Data Collection subtasks checked off (Asana advances automatically)

## Proposal Building

- [ ] Standard proposal template used
- [ ] Phase 1 GEOs generated
- [ ] Proposal Deck, Executive Summary, and Creative Brief linked on parent task
- [ ] Technical / billing custom fields validated (no config conflicts)
- [ ] Margin / pricing within policy (or Head of Sales written approval)

## Leadership Review

- [ ] Leadership approved proposal
- [ ] SAE verified all parent-task fields
- [ ] Ready for Client Proposal Review (do not present before this gate)

## Client Proposal Review → Contracting

- [ ] Client validated goals, tracking/billing path, GEO, spend, and commercial terms
- [ ] Client agreed to proceed
- [ ] IO issued (+ affiliate addendum if fields require it)
- [ ] Signed docs attached to parent task

## Alternate paths

- [ ] **Purgatory**: timing not right → future follow-up task + expected date + Clarify On Hold
- [ ] **Disqualified**: not viable → Clarify Closed-Lost with reason; do not leave in active stages

## After signature

Continue on [Contract Signed Handoff Checklist](./contract-signed-handoff.md). Do **not** complete the parent task when SAE work ends.
