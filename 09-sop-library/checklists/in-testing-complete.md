# Checklist: In Testing → Complete

> **Department / Section**: 09-sop-library / checklists  
> **Supports**: [Campaign Launch](../../04-customer-success/campaign-launch.md)  
> **Owner**: Assigned CSM (CSE owns incrementality analysis)  
> **Last Reviewed**: 2026-10-08

Use after Take Live activation. The parent task stays open until Incrementality Testing finishes.

---

## Immediately after go-live

- [ ] Campaign live; line items bidding
- [ ] Client launch email sent + dashboard access provided
- [ ] Internal Slack announcement posted
- [ ] Promo terms / credits sent to Accounting (or N/A)
- [ ] Everflow Pay recurring reminder set (or N/A)
- [ ] Parent task in **In Testing**
- [ ] Account Status = Live; Launch Date set
- [ ] Accounting notified if affiliate-platform billing replaces direct invoicing
- [ ] Incrementality moved from queue into active testing (Week 0)

## Early checks

- [ ] T+4h pacing / win-rate inspection done
- [ ] T+24h attribution / conversion spot-check done
- [ ] One-week campaign volume check done
- [ ] Zero-impression or overpace issues escalated to Ad Ops if needed

## Complete the parent task only when

- [ ] Incrementality Testing complete per Client Success incrementality workflow
- [ ] No open launch-blocking work remains on the shared parent
- [ ] Parent task marked **Complete** in Onboarding Overview
