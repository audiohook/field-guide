# Checklist: Onboarding Stage Gates

> **Department / Section**: 09-sop-library / checklists  
> **Supports**: [Client Onboarding](../../04-customer-success/client-onboarding.md)  
> **Owner**: Assigned CSM (specialists own their subtasks)  
> **Last Reviewed**: 2026-10-08

Onboarding Overview is the high-level board. Specialized work stays in Creative / Tracking / Billing projects via multi-homing.

```
New Contract Assignment → Setup and Intro → Call Pending
  → Campaign and Creative → Take Live → In Testing → Complete
```

---

## New Contract Assignment

- [ ] CSM owns parent task ([handoff checklist](./contract-signed-handoff.md) done)
- [ ] Parallel routes visible as needed: tracking, billing, affiliate, incrementality, referral
- [ ] No second parent task created

## Setup and Intro

- [ ] Client Asana project created in Clients portfolio
- [ ] Google Drive client folder created and linked
- [ ] Reply to Sales introduction sent
- [ ] Onboarding work connected to the client project

## Call Pending → Onboarding Call

- [ ] Call scheduled (target: within 3 business days of CSM assignment)
- [ ] Prep: onboarding deck/template + Sales context + client requirements
- [ ] Call completed; goals, audience, GEO, KPIs confirmed
- [ ] Follow-ups documented in client Asana project
- [ ] Onboarding Call Status = Complete

## Campaign and Creative (parallel)

- [ ] Parent multi-homed into Creative Overview; Creative owns production
- [ ] Billing path complete for this client’s fields (Stripe / affiliate terms / $0 CPA reporting-only)
- [ ] Tracking subtasks complete in the correct tracking project(s); test conversions visible
- [ ] Campaign settings configured in Audiohook UI as required
- [ ] Referral reporting confirmed if applicable
- [ ] Clarify client record current
- [ ] CSM monitors readiness; does not run Creative production

## Ready for Take Live?

Only when every dependency above is done → [Take-Live Readiness Checklist](./take-live-readiness.md).

## Canceled

- [ ] Client will not launch → move to Canceled + update Clarify
