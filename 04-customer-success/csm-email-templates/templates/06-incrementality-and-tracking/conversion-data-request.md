# Conversion Data Request (Ongoing Incrementality)

**When to use:** Request 150 days of conversion data plus weekly updates to measure incremental lift.

---

Hi [Client Name],

To help us validate campaign impact and ensure tracking is maintained, we'll need 150 days of conversion data for [Conversion Event] across all channels.

Please provide a file with one conversion per row, formatted as:

- Column A: State where the conversion occurred.
- Column B: Date of the conversion.
- Column C: Revenue associated with the conversion.

Please do not include any PII. We'll also request an updated version of this data weekly so we can continue measuring changes in incremental lift as the campaign progresses.

For more context on why we request this data, you can [read more here](https://audiohook.substack.com/p/why-we-ask-for-weekly-conversion).

Let me know if you have any questions!

[CSM]
